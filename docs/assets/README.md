# Cabin Assistant dashboard recording

`cabin-assistant.gif` is a recording of the running local application on 2026-10-10: real street footage, a scene question, a simulated 20 °C tool action, and NVIDIA NeMo execution events. It is approximately 24 seconds, 1200×767 pixels, loops continuously, and is smaller than 10,000,000 bytes. Captured at approximately 8 fps and exported at 5 fps with an optimized palette. Waiting time between capture segments was omitted; the visible answers and timings come from the actual run.
